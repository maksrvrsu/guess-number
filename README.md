# Игра «Угадай число» на Go

Простая консольная игра, в которой нужно угадать случайное число за ограниченное количество попыток. В игре есть уровни сложности, история попыток и подсказки по расстоянию до числа.

## Как запустить
Убедитесь, что у вас установлен Go. Откройте терминал в папке с игрой и введите команду:
```bash
go run main.go
```

## Пример вывода
```text
Выберите сложность:
1 - Легкий (1-50, 15 попыток)
2 - Средний (1-100, 10 попыток)
3 - Сложный (1-200, 5 попыток)
Ваш выбор: 2

Игра 'Угадай число' - от 1 до 100 началась!
Угадайте число за 10 попыток!

Попытка #1 - Введите число: 50
Секретное число меньше 👇
Подсказка: ❄️ Холодно
```
